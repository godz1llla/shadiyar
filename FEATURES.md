# Новые функции приложения "Тірі Тарих"

## GPS и геолокация

- **Определение текущего местоположения**: Приложение определяет ваше текущее местоположение с помощью GPS
- **Отображение на карте**: Ваше местоположение отображается синим маркером на карте
- **Кнопка "Моя локация"**: Быстрый переход к вашему текущему местоположению

## Построение маршрутов

- **Маршрут к объекту**: При нажатии на маркер объекта можно построить маршрут от вашего местоположения до объекта
- **Визуализация маршрута**: Маршрут отображается оранжевой линией на карте
- **Автоматическое масштабирование**: Карта автоматически масштабируется для отображения всего маршрута

## Геофенсинг (автоматическое определение приближения)

- **Автоматическое определение**: Приложение автоматически определяет, когда вы приближаетесь к объекту
- **Радиус срабатывания**: По умолчанию 100 метров (можно настроить для каждого объекта)
- **Автоматическое уведомление**: При приближении к объекту появляется уведомление

## Голосовое повествование

- **Автоматическое воспроизведение**: При приближении к объекту автоматически запускается голосовое повествование на казахском языке
- **Текст для озвучивания**: Каждый объект имеет свой текст для голосового повествования
- **Казахский язык**: Используется казахский язык для TTS (Text-to-Speech)

## Видео о местах

- **Автоматическое открытие**: При приближении к объекту можно открыть видео о нем
- **Видео плеер**: Встроенный видео плеер с управлением (play/pause)
- **Описание объекта**: Под видео отображается полное описание объекта на казахском языке
- **Аудио текст**: Отображается текст, который был озвучен

## Как использовать

1. **Открыть карту**: Перейдите на экран "Карта"
2. **Определить местоположение**: Нажмите на кнопку GPS (синяя кнопка в правом верхнем углу)
3. **Выбрать объект**: Нажмите на маркер объекта на карте
4. **Построить маршрут**: Нажмите "Маршрут құру" в меню объекта
5. **Следовать маршруту**: Следуйте по оранжевой линии на карте
6. **Приближение**: При приближении к объекту (в пределах 100 метров):
   - Автоматически запустится голосовое повествование
   - Появится диалог с предложением посмотреть видео
   - Можно открыть видео и прочитать полное описание

## Технические детали

- **GPS**: Используется библиотека `geolocator` для определения местоположения
- **Маршруты**: Используется OSRM API для построения маршрутов
- **Голосовое повествование**: Используется `flutter_tts` с поддержкой казахского языка
- **Видео**: Используется `video_player` для воспроизведения видео
- **Геофенсинг**: Реализован через отслеживание расстояния до объекта

## Разрешения

Приложение запрашивает следующие разрешения:
- **ACCESS_FINE_LOCATION**: Для точного определения местоположения
- **ACCESS_COARSE_LOCATION**: Для приблизительного определения местоположения
- **INTERNET**: Для загрузки карт, маршрутов и видео
