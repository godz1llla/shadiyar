## Функциональность

### Основные возможности:

1. **Умный AI помощник**: 
   - Отвечает на вопросы о Кызылординской области
   - Предоставляет информацию об исторических местах
   - Дает советы по туризму
   - Отвечает только на казахском языке

2. **Контекстная поддержка**:
   - Знает об объектах в приложении (Қорқыт Ата, Сығанақ и др.)
   - Может давать рекомендации на основе контекста
   - Предлагает планы на день

3. **Интеграция**:
   - Используется в модальном окне AI помощника
   - Автоматическая обработка ошибок
   - Индикатор загрузки при запросе

## Использование

AI помощник доступен через:
- Плавающую кнопку AI на главном экране
- Модальное окно с чатом
- Отправка сообщений и получение ответов от Gemini

## Безопасность

⚠️ **Важно**: API ключ хранится в коде. Для production версии рекомендуется:
- Использовать переменные окружения
- Хранить ключ на сервере
- Использовать proxy для запросов

## Модель

Используется модель `gemini-1.5-flash` от Google:
- Высокое качество ответов
- Быстрая скорость генерации
- Поддержка казахского языка
- Контекстное понимание
- Оптимизирована для диалоговых приложений

**Доступные модели:**
- `gemini-1.5-flash` - быстрая и эффективная (рекомендуется)
- `gemini-1.5-pro` - более мощная, но медленнее
- `gemini-pro` - устарела, не рекомендуется
