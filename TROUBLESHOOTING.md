# Решение проблем с Gemini API

## Типичные ошибки и их решение

### 1. "Қате орын алды" (Общая ошибка)

**Возможные причины:**
- Проблемы с интернет-соединением
- Неверный API ключ
- Превышен лимит запросов
- Проблемы на стороне сервера Gemini

**Решение:**
1. Проверьте интернет-соединение
2. Убедитесь, что API ключ правильный
3. Проверьте лимиты в Google Cloud Console
4. Попробуйте позже

### 2. "API кілті дұрыс емес немесе жарамсыз"

**Причина:** API ключ неверный или неактивен

**Решение:**
1. Проверьте API ключ в `lib/services/gemini_service.dart`
2. Убедитесь, что ключ активен в Google Cloud Console
3. Проверьте, что Gemini API включен в вашем проекте
4. Создайте новый API ключ при необходимости

### 3. "Интернет байланысы жоқ"

**Причина:** Нет подключения к интернету или проблемы с сетью

**Решение:**
1. Проверьте Wi-Fi или мобильный интернет
2. Попробуйте открыть другой сайт
3. Перезапустите приложение
4. Проверьте настройки файервола

### 4. "API лимиті асып кетті"

**Причина:** Превышен дневной/месячный лимит запросов

**Решение:**
1. Проверьте квоты в Google Cloud Console
2. Дождитесь обновления лимита (обычно в начале дня/месяца)
3. Рассмотрите возможность увеличения лимита
4. Оптимизируйте количество запросов

### 5. "Жауап қауіпсіздік себептерімен блокталды"

**Причина:** Контент заблокирован фильтрами безопасности Gemini

**Решение:**
1. Переформулируйте вопрос
2. Избегайте чувствительных тем
3. Используйте более нейтральные формулировки

## Диагностика

### Проверка API ключа

1. Откройте файл `lib/services/gemini_service.dart`
2. Найдите строку с `_apiKey`
3. Убедитесь, что ключ правильный: `AIzaSyAKApoolhZAtijBZiodAS4SR2d-1_My13k`

### Проверка подключения

Запустите приложение и попробуйте задать простой вопрос:
- "Сәлем"
- "Қызылорда туралы айтыңыз"

### Просмотр логов

В консоли разработчика будут выводиться детальные ошибки:
```
Gemini API Error: [детали ошибки]
```

## Настройка Gemini API в Google Cloud

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Выберите ваш проект
3. Включите Gemini API
4. Создайте API ключ
5. Настройте ограничения (опционально)

## Альтернативные решения

Если проблемы продолжаются:

1. **Использовать fallback**: Добавить локальные ответы при ошибках API
2. **Кэширование**: Кэшировать частые вопросы
3. **Retry логика**: Повторять запросы при временных сбоях
4. **Офлайн режим**: Использовать локальные данные при отсутствии интернета

## Контакты

При постоянных проблемах:
- Проверьте документацию Gemini API
- Обратитесь в поддержку Google Cloud
- Проверьте статус сервисов Gemini
